# Echo Lego Project

这是一个基于Python的项目，主要包含以下文件：

- `step2_0818_original.py`: 原始实现文件
- `step2_beamsearch.py`: 实现beam search算法的文件
- `step2_0818.py`: 2018年8月18日版本
- `step2_0819.py`: 2018年8月19日版本
- `step2_0819_training.py`: 训练相关实现
- `validation.py`: 验证功能实现
- `run.sh`: 运行脚本

## 运行环境

- Python 3.x

## 使用方法

执行以下命令运行项目：

```bash
./run.sh
```
